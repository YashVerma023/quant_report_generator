Formulas & methodology

  • Daily return (rt) = sum_mtmt / sum_allocationt  |  sum_allocation = Σ(raw_allocation × 100) across all users of that algo on date t. Returns are expressed as fractions; multiplied by 100 for display as %.
  • Cumulative Return = Σ rt   (simple additive sum, not compounded). The equity curve is the running cumulative sum of daily returns.
  • CAGR = mean(rt) × N  |  N = 188.7 trading days/yr, derived as: distinct trading dates ÷ calendar years spanned. This is a simple linear annualisation of the mean daily return (not geometric compounding).
  • Annual Volatility = std(rt, ddof=1) × √N  |  Sample standard deviation of daily returns annualised by √N.
  • Sharpe Ratio = (mean(rt) − rf/N) / std(rt) × √N  |  rf = 0.0% p.a. (risk-free rate). Penalises both upside and downside volatility equally.
  • Sortino Ratio = (mean(rt) − rf/N) / DD × √N  |  DD (downside deviation) = √(mean(min(rt, 0)2)). Only penalises negative-return days; flat/zero days are treated as losses.
  • Max Drawdown = min(equityt − peakt) where peakt = max(equity0..t). Measured on the additive equity curve; path-dependent metrics use the largest contiguous segment.
  • Avg Drawdown Days = mean length (trading days) of underwater episodes, where an episode starts when equity falls below its prior peak and ends when it fully recovers.
  • Calmar Ratio = CAGR / |Max Drawdown|. Higher is better. Uses the largest contiguous segment for the drawdown.
  • Kelly Criterion = W − (1 − W) / R  |  W = win rate (fraction of days with rt > 0); R = avg winning return / avg |losing return|. Negative Kelly means do not size up on this setup.
  • Rolling Sharpe (63d): Sharpe formula applied over a rolling 63-trading-day window across the full series. The line starts once the first window fills. Stable values > 1 indicate consistent performance.
  • Consecutive Wins/Losses: longest streak of days with r > 0 (wins) or r ≤ 0 (losses) on the largest contiguous segment.
  • Broker whitelist: only rows with broker in {GyandeepStocks, Kredent, MastertrustPro, SISL, VT_Capital} (case-insensitive) are retained across ALL algos before any scaling, aggregation, or return calculation. All other brokers are excluded.
  • Processed data columns (Excel): PNL% = (sum_mtm / sum_allocation) × 100  |  Base Capital = 10,000,000 (fixed 1 crore)  |  Absolute PNL = (sum_mtm / sum_allocation) × Base Capital. These columns show what you would have earned/lost on a 1-crore base capital.
  • Data quality: rows in = 106,013 | broker-excluded (not in whitelist) = 102,364 | unparseable date = 0 | null mtm = 0 | null/≤0 allocation = 0 | duplicate (user, algo, date) = 0.
