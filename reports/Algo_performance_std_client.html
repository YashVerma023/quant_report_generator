ℹ Methodology assumptions

  • Risk-free rate: 6.5% p.a. — 3-year average of Indian 91-day T-Bill (2022–2025). Applied daily as rf daily = 6.5% ÷ N when computing Sharpe, Sortino, and Rolling Sharpe.
  • Rolling Sharpe window — 63 trading days (≈ 1 calendar quarter): One quarter is the shortest window that captures a full earnings/expiry cycle. It smooths day-to-day noise while still being short enough to flag a strategy regime change within the same year. The Rolling Sharpe line is absent for the first 63 trading days of each algo (warm-up period).
  • * Return values (CAGR, Cumulative Return): Marked with * to indicate these are additive fractional returns — daily rt = sum_mtm / sum_allocation, summed linearly for Cumulative Return and geometrically annualised for CAGR. They are not compounded mark-to-market returns.
  • Short-history caveat: CAGR and Calmar are unreliable for algos with < 1 year of data — the quant reference guide recommends ≥ 3 years for Calmar. Algos flagged ⚠ <1 yr should be interpreted with this caveat in mind.
